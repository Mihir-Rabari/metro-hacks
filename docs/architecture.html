Fariyad — System Architecture

PS-07 · Every Complaint Heard — offline-first grievance triage for GMRC · built on board the Gujarat Metro · everything inside the left boundary runs in airplane mode

Offline-first, provably

  • • APK ships with zero INTERNET permission
  • • Fake origin https://fariyad.local unlocks IndexedDB + WASM
  • • Airplane mode is the norm, not the test
  • • Neural model runs fully on-device (118 MB WASM)

Built once, delivered twice

  • • bake.py inlines everything → dist/app.html (688 KB)
  • • CI fetches the HF model → signs Fariyad.apk (74 MB)
  • • GitHub Release is the pipeline — no SDK on the laptop
  • • Repo push = new APK, sha256 published

Dual-engine AI — 86.4%

  • • NB domain engine (79.5%) + multilingual MiniLM (70.5%)
  • • Margin-gated ensemble, rule fixed before scoring
  • • Both engines' opinions shown as chips on every ticket
  • • Receipts: models/eval.json · scripts/eval_neural.py
